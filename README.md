# Fraud Detection System

## 📌 Overview

Fraud Detection System is a microservices-based backend application
developed using Spring Boot.

The system processes financial transactions and detects potentially
fraudulent transactions using a distributed microservices architecture.

## 🏗️ Architecture

The project consists of the following services:

- API Gateway
- Account Service
- Transaction Service
- Payment Service
- Fraud Detection Service
- Notification Service

## 🛠️ Technologies Used

- Java
- Spring Boot
- Spring Cloud
- Spring Data JPA
- MySQL
- Apache Kafka
- Redis
- Docker
- REST API
- Maven

## 🔧 Microservices

### 1. Gateway
Acts as the entry point for client requests and routes requests
to the appropriate microservice.

### 2. Account Service
Manages account-related operations.

### 3. Transaction Service
Handles transaction-related operations.

### 4. Payment Service
Processes payment-related operations.

### 5. Fraud Detection Service
Analyzes transaction events and identifies potentially fraudulent
transactions.

### 6. Notification Service
Handles notifications generated by the system.

## 🔄 Communication

The services communicate using:

- REST APIs
- Apache Kafka for asynchronous event communication

## ⚡ Redis

Redis is used for caching frequently accessed data and improving
application performance.

## 🐳 Docker

Docker is used to containerize the application infrastructure
and run required services.
